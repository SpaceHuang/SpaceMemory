# docs/explain —— 解释层（给人看的说明与图）

> **定位**：架构图、网页格式（HTML）的易读说明与介绍。服务对象是人，不是执行体。
> **非权威声明**：本目录是展示与解释层，**不承载任何规则**——规则只住设计文档、规范（`docs/specs/`）与操作指南（`docs/rules/`）；本目录与它们冲突时，以规范与设计文档为准。内容只做引用与可视化，不做第二事实源（避免双源漂移）。
> **触发关系**：不需要预读本目录即可做任何开发任务——它有意不在 AGENTS.md 触发必读表中。

## 纪律

- 本目录按"评审者文档"标准写：阐述自说明、引用不承重（`docs/rules/document-writing.md` §0-4 打印测试）——读者不该为了看懂一张图再去翻设计文档；
- 图与说明中出现的机制细节必须与真源一致；发现不一致，改的是本目录（真源不动），或作为异议提评审；
- 网页保持零依赖：纯 HTML/CSS、不引外部 CDN，克隆仓库即可离线打开。
