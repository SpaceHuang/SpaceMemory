# memory 约定

## 载荷字段语义
- `title`：一句话概括（检索靠它）；正文放完整记忆。
- `topic`：挂到主题面；无合适主题先空着，维护例程会提案。
- 未知字段容忍（lenient）但不要发明平行字段——同类信息用同名，避免记录退化为浆糊（R8 反例）。

## 生命周期
- 一条记忆一个事实/教训；不要堆砌长文（预算原则）。
- 过时记忆：更新原记录（收敛，R5.4），不新建；被现实推翻且无价值 → 显式删除（进 attic）。

## 提炼与引用
- 多条 memory 沉淀出 lesson/decision 时，用派生引用指回证据（R9.2），提炼产物携带证据截止（evidence_cutoff_seq）。
